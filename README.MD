# VulBench-CPP: A Multi-Tier Benchmark for Evaluating Security of AI-Generated C++ Code

Replication package for the empirical study combining static analysis, runtime sanitization, and formal verification to characterize vulnerability patterns in C++ code generated by large language models.

## Overview

This study analyzes **8,918 C++ programs** (7,223 AI-generated + 1,695 human-written) across 851 competitive programming tasks from the CodeContests dataset. We combine three tiers of analysis — static, dynamic, and formal verification — to characterize vulnerability patterns and cross-tool agreement.

**Key finding**: Cross-tool Jaccard similarity between ESBMC and ASan/UBSan is ~0.05, demonstrating that each tier exposes hundreds of unique vulnerability instances invisible to the others.

## Models

- **Gemma 3 27B IT**
- **LLaMA 3.3 70B Instruct**
- **Qwen 2.5 Coder 32B Instruct**

## Baseline

- **Human C++ solutions** from google-deepmind/code_contests (two reference implementations per problem)

## Analysis Pipeline

| Tier | Tool | Purpose |
|------|------|---------|
| Functional testing | g++ 13.3.0 + test suites | Correctness evaluation (10s timeout) |
| Static analysis | cppcheck 2.19.0 | CWE detection and code quality (30s timeout) |
| Static analysis | clang-tidy 21 | Path-sensitive security diagnostics |
| Dynamic analysis | ASan / UBSan | Runtime memory-safety violation detection |
| Formal verification | ESBMC v8.0.0 | Bounded model checking (SMT-based) |

## Quick Start

```bash
# Install dependencies
pip install pandas numpy scipy matplotlib seaborn pyarrow jupyter

# Run Steps 1–7 (static + dynamic)
python3.11 scripts/run_full_analysis.py

# Add ESBMC formal verification (Step 8) — three configurations
# Config 1: overflow-check, unwind=10, timeout=60s
python3.11 scripts/run_full_analysis.py --skip-extract --skip-tests \
    --skip-cppcheck --skip-clang-tidy --skip-sanitizers --skip-parse --skip-merge \
    --esbmc --esbmc-tag esbmc_overflow

# Config 2: overflow-check, deeper unwind=20, timeout=120s
python3.11 scripts/run_full_analysis.py --skip-extract --skip-tests \
    --skip-cppcheck --skip-clang-tidy --skip-sanitizers --skip-parse --skip-merge \
    --esbmc --esbmc-tag esbmc_deep --esbmc-unwind 20 --esbmc-timeout 120

# Or run individual steps — see REPLICATION.md for details
```
